1. **PRODUCTION LAW honored**: every verdict below was produced by
   `bun journeys/runner.ts --base-url https://webflix-steel.vercel.app …`
   (the runner's own manifest is the artifact of record).
2. **Chunked execution**: this sandbox reaps backgrounded processes at each
   tool-call boundary (proven — see partial-results.md), so the 38-journey
   suite ran as 8 sequential foreground chunks, each a full runner invocation
   (fresh isolated browser session per chunk — the fresh-state law holds;
   fixed 1280×800 viewport; the runner's acquisition/source-auth drive-state
   resets ran per chunk). Catalog order preserved; the scripted-acquisition
   chain J21→J26 kept whole in one chunk (the runner's own chain law).
   Evidence: `run/chunk-01..08/` (each with manifest.json + summary.md +
   per-journey screenshots/snapshots/narrations + failure captures).
3. **The flaky-check discipline (the adjudication law)**: EVERY non-pass was
   re-run (`rerun/chunk-01..08/`). All 34 reproduced the same VERDICT →
   **zero verdict flakes, all verdict-stable**; 33/34 with the identical
   first-failing assertion. **J36's re-run is the one recorded failure-mode
   divergence**: the re-run failed at an earlier browser-harness wait (the
   `[data-wfx-session-signed-in]` wait timed out at 25s / the agent-browser
   proc at 20s) instead of the run-of-record journey assertion (the BYOF
   source card absent) — the FAIL verdict is stable either way; the
   run-of-record failure remains the adjudicated basis. Mechanical proof:
   `run/consolidated-manifest.json` (generated by
   `run/consolidate-manifests.py` — a merge of the runner's own manifests;
   every check green).
4. **The local fixtures baseline (adjudication support, labeled as such)**:
   the current tree booted in its own documented deterministic fixtures mode
   (the R23 record's configuration — `WFX_DEV_FIXTURES=1`, port 3101) and the
   same 38 journeys run against it (`local-baseline/full..full5/`). This
   separates TREE-LEVEL grammar drift (fails locally AND on production) from
   PRODUCTION-ONLY deltas (fails on production, passes locally). Per the
   production law, this local boot is used ONLY to adjudicate production
   findings — never as a substitute verdict.
