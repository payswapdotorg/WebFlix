## The frozen laws — compliance

- **Never fabricate**: every number in `TABLES.md`/`ACCEPTANCE-SUMMARY.md`/`LEDGER.md`
  is either a typed-marker offset from `raw/*.json`, a count of those records, or a
  verbatim VLM quote. Blocked cells say BLOCKED; uncaptured rows say not-captured.
- **Same content**: the walk registry (`scripts/walk.sh`) pins both ids per item —
  WebFlix canonical id + provider ref — in every raw record; the battery ran the same
  identity pairs for the (blocked) YouTube side and the WebFlix side.
- **Thresholds verbatim**: quoted word-for-word from the J41 spec in
  `ACCEPTANCE-SUMMARY.md`; no threshold was reinterpreted or softened.
- **Production target**: every walk hit `https://webflix-steel.vercel.app` exactly
  (the `url` field in every harvest is the proof).
- **Honest instrumentation**: the harness drives the real user path (item hub → real
  click) and harvests `window.__wfxPlaybackTelemetry` /
  `window.__wfxStartupObservations` verbatim; the only external timing is the click
  epoch bridge the product itself records.

## Reproduction

```
bun test                                   # G2 (expect 5256/1/0)
bash evidence/r34b/scripts/cell.sh rick cold 11 60   # resumable: skips existing records
python3 evidence/r34b/scripts/aggregate.py  # cell stats -> aggregate.json
python3 evidence/r34b/scripts/tables.py     # TABLES.md from raw/
```

The walk battery requires the live production target and a non-bot-gated provider
path for the playable cells; in a gated environment the refused cells reproduce as
honest timeout rows (46/46 this run).
